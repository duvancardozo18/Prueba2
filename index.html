Acerca del buscador

Consulta el servicio ArcGIS REST de Catastro Bogotá, clasifica cada unidad por su dirección oficial (AP apartamento, GJ garaje, IN interior) y usa el CHIP como identificador interno para descartar duplicados. El CHIP se incluye en los archivos descargados.

El endpoint no se ha podido verificar desde el entorno de desarrollo. Si el navegador bloquea la consulta (CORS) use la carga manual de JSON de abajo.
